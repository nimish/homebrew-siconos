# Nimish Siconos

## How do I install these formulae?

`brew install nimish/siconos/<formula>`

Or `brew tap nimish/siconos` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nimish/siconos"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
